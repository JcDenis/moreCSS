Feuille de style
Écrivez vos règles CSS, elles s'ajoutent après celles du thème actif. Si une règle ne change rien, le thème style un élément intérieur ou utilise un sélecteur plus précis : inspectez le texte dans votre navigateur et reprenez ce sélecteur. Le CSS est réduit : évitez un espace avant deux-points (.menu *:hover, pas .menu :hover).
Autoriser la feuille de style additionnelle
Décochez la case et enregistrez pour ne plus utiliser les règles sans les effacer. Les règles s'appliquent à l'écran, pas à l'impression.
