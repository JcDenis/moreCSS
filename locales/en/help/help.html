Style sheet
Write your own CSS rules, they are added after the ones of the active theme. If a rule changes nothing, the theme styles an inner element or uses a more precise selector: inspect the text in your browser and use that selector. The CSS is minified: avoid a space before a colon (.menu *:hover, not .menu :hover).
Enable additional CSS
Uncheck the box and save to stop using the rules without erasing them. The rules apply on screen, not in print.
